# Changelog

## 0.2
- Fixes after review: the followed commands were not read back correctly (nothing was learnt), disabling the plugin no longer empties the table, smoothed history imported only for its last hours (and flagged), abnormally long switch-ons discarded, unreadable entered period refused, absence command checked, a command added later is imported from history, “Erase all” button, trends kept in a file.
- Wording: the plugin does not “learn”, it draws trends from your history. Added: earliest, latest, average, shortest and longest durations, hours a lamp is never on, shutter never or always closed at night, exceptions (rare hours, days far from the middle half).

## 0.1
- First version: learning only. Choice of followed lights and shutters (recommended by generic type), import of the Jeedom history, hour-by-hour profiles (weekday / weekend), durations, lamps switched on together, shutter times, absence periods excluded. Nothing leaves the box; no action on devices.
